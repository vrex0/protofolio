# VREX Portfolio

A warm, bilingual personal developer portfolio built with plain HTML, CSS, and JavaScript.

The interface follows a cream-and-orange editorial style inspired by the supplied reference, with standalone language and theme controls, responsive navigation, subtle motion, RTL support, persistent preferences, and local recognizable language logo images.

## Contact setup

The only public/contact address is `vrexdev9@gmail.com`. GitHub is linked to `https://github.com/Vrex0`. The form opens a prefilled email draft addressed to `vrexdev9@gmail.com`; because this is a static site, it does not claim delivery and depends on the visitor's email application.

## Customize

Edit the `skills` and `projects` arrays in `script.js`. Add real projects only when they are ready to share. Language icon SVGs live in `assets/` and can be replaced independently.

Open `index.html` directly in a browser or serve the folder with any static HTTP server.
